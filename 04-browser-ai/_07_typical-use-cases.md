# Browser AI: Running Machine Learning Client-Side — Typical use cases

- In-browser image classification / object detection on webcam frames
- Real-time background removal / virtual backgrounds in video-calling web apps
- Local semantic search / embeddings generation (no data sent to a vector-DB API)
- On-device translation and summarization of page content
- Local chat assistants via WebLLM for privacy-sensitive or offline scenarios
- Accessibility features: live captioning, OCR, text-to-speech, all client-side
