# Local Speech Models — Further reading

- OpenAI Whisper paper ("Robust Speech Recognition via Large-Scale Weak Supervision") and the `openai/whisper` GitHub repo.
- `ggml-org/whisper.cpp` GitHub repo — build instructions, quantization, streaming examples.
- Vosk documentation (alphacephea.com / `alphacep/vosk-api` on GitHub).
- Piper TTS GitHub repo (`rhasspy/piper` or its current community fork) — voice list and training guide.
- Picovoice Porcupine documentation, and the `dscripka/openWakeWord` GitHub repo.
- Apple's Speech framework documentation (`SFSpeechRecognizer`) and Android's `SpeechRecognizer` API docs.
