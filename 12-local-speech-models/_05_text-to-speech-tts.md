# Local Speech Models — Text-to-speech (TTS)

- **Piper** (Rhasspy project / community-maintained) — a fast, local neural TTS engine using small per-voice ONNX models (tens of MB), designed to run in real-time even on a Raspberry Pi; a popular default for offline voice assistants.
- **Coqui TTS / XTTS** (community-maintained after Coqui's shutdown) — open TTS models including voice-cloning-capable variants, heavier than Piper but higher quality/flexibility.
- **On-device OS neural TTS** — iOS/macOS's enhanced/neural Siri voices and Android's on-device TTS engine (used by TalkBack and offline Assistant features) ship as part of the OS, not as separately distributed models.
