# WebAssembly (WASM) for Edge & On-Device AI — Further reading

- WebAssembly.org — official specification, roadmap, and proposals (SIMD, threads, Component Model)
- Bytecode Alliance — Wasmtime, WASI, and Component Model documentation
- Emscripten documentation (emscripten.org) — the standard C/C++ → WASM toolchain
- `wasm-pack` and `wasm-bindgen` documentation — the standard Rust → WASM toolchain
- ONNX Runtime Web documentation — WASM backend build flags (SIMD/threads)
- llama.cpp and whisper.cpp GitHub repositories — WASM build targets and browser demos
- MDN Web Docs — WebAssembly guides, `SharedArrayBuffer`, and cross-origin isolation requirements
- Cloudflare Workers / Fastly Compute documentation — WASM at the CDN edge
