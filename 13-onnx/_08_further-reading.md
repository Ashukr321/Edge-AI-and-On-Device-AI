# ONNX & ONNX Runtime — Further reading

- ONNX project and spec: https://onnx.ai and the `onnx/onnx` GitHub repository (operator spec docs under `docs/Operators.md`).
- ONNX Runtime documentation: https://onnxruntime.ai — Execution Providers reference, quantization guide, mobile guide.
- PyTorch ONNX export documentation (`torch.onnx`) in the official PyTorch docs.
- Netron: https://github.com/lutzroeder/netron
- Microsoft Olive: https://github.com/microsoft/olive
- HuggingFace Optimum ONNX Runtime guide, for exporting and accelerating Transformers models.
