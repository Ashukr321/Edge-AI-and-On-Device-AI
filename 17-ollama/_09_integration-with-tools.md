# Ollama — Integration with tools

- **LangChain / LlamaIndex** — both have first-class `Ollama` integration classes that talk to the local REST/OpenAI-compatible API, making it easy to drop into existing RAG or agent pipelines.
- **Open WebUI** — a popular self-hosted ChatGPT-style web frontend that talks to an Ollama backend, adding chat history, multi-user accounts, and RAG document upload on top of it.
- **Continue.dev / other IDE copilots** — support Ollama as a local backend for code completion/chat inside VS Code and JetBrains IDEs.
- **n8n / Flowise** and other low-code automation tools — ship built-in Ollama nodes for local-LLM steps in a workflow.
