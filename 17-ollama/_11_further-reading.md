# Ollama — Further reading

- Ollama documentation (ollama.com and the `ollama/ollama` GitHub repo's `docs/` folder) — API reference, Modelfile reference, and environment variable list.
- Ollama's model library at ollama.com/library for available models and tags.
- `open-webui/open-webui` GitHub repo for the web UI project.
- LangChain and LlamaIndex documentation sections on their respective Ollama integrations.
