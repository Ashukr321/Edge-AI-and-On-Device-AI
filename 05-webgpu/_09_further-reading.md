# WebGPU for Machine Learning — Further reading

- W3C WebGPU specification and WGSL specification (gpuweb.github.io)
- MDN Web Docs: WebGPU API reference and guides
- "WebGPU Fundamentals" (webgpufundamentals.org) — practical tutorials including compute shaders
- Google Chrome for Developers: WebGPU launch and best-practices articles
- TensorFlow.js WebGPU backend documentation and source (`tfjs-backend-webgpu` on GitHub)
- ONNX Runtime Web documentation — WebGPU Execution Provider
- MLC-LLM / WebLLM project (GitHub: mlc-ai/web-llm) and its TVM/MLC compilation background
- `wgpu` (gfx-rs) and Dawn (Google) project repositories for native WebGPU implementations
