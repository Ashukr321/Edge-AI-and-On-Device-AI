# Edge AI Architecture — Tools & frameworks

- **NVIDIA Fleet Command / Jetson tooling** — device fleet management for
  edge GPU deployments.
- **AWS IoT Greengrass, Azure IoT Edge, Google Cloud IoT** — managed
  OTA deployment and device management planes.
- **MLflow / Weights & Biases** — model versioning and experiment
  tracking, feeding into edge deployment pipelines.
- **TensorFlow Extended (TFX)** and **Kubeflow Pipelines** — orchestrating
  the train → validate → convert → push pipeline.
- **ONNX** — the common interchange format tying frameworks and runtimes
  together across this whole pipeline.
- **Flower / TensorFlow Federated** — federated learning frameworks.
- **Edge Impulse** — integrated data → train → optimize → deploy workflow
  aimed specifically at TinyML/embedded targets.
