# Local Vision Models — Overview

Edge computer vision predates the local-LLM wave by nearly a decade — mobile-optimized CNNs like MobileNet (2017) were designed explicitly for on-device inference. Today's edge vision stack spans small, fast task-specific models (classification, detection, segmentation, pose) and, more recently, compact vision-language models (VLMs) that can describe images or answer questions about them, all running on-device.
