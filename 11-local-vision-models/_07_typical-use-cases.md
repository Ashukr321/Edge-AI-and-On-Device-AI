# Local Vision Models — Typical use cases

- **Real-time camera apps**: live object/person detection, AR filters, background blur/replacement in video calls.
- **Offline document scanning**: on-device edge/corner detection plus OCR (e.g. combined with Tesseract or a small on-device OCR model) for scanning receipts/documents without uploading them.
- **Industrial/quality inspection**: defect detection on embedded devices at the production line, where network latency or connectivity can't be relied on.
- **Robotics and drones**: obstacle detection, visual odometry, and navigation running on embedded GPUs (e.g. NVIDIA Jetson) with no cloud dependency.
- **Accessibility**: on-device scene description and text recognition for visually impaired users, where privacy and offline reliability both matter.
