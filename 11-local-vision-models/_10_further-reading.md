# Local Vision Models — Further reading

- Ultralytics YOLO documentation (docs.ultralytics.com) — model zoo, export formats, benchmarks.
- Google MediaPipe Solutions guide — Tasks API for vision, audio, and text.
- TensorFlow Lite / LiteRT documentation — delegates, model conversion, quantization guide.
- ONNX Runtime documentation — Execution Providers reference.
- Moondream and SmolVLM model cards on Hugging Face.
- Apple's Core ML Tools documentation and WWDC sessions on on-device ML.
