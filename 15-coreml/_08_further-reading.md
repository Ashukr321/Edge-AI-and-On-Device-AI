# Core ML — Further reading

- Apple's Core ML documentation and coremltools documentation: developer.apple.com/documentation/coreml and the `coremltools` docs (readthedocs, linked from the `apple/coremltools` GitHub repository).
- WWDC sessions on Core ML and coremltools optimization (available in Apple's developer video library) — regularly updated with each OS release's new compute/quantization features.
- Vision framework documentation: developer.apple.com/documentation/vision
- `apple/coremltools` GitHub repository, including the `coremltools.optimize` guide for quantization and palettization APIs.
- Create ML documentation: developer.apple.com/documentation/createml
