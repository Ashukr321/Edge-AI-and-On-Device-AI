# Frontend + Edge AI Integration

A guide for frontend developers on building applications that run AI models
directly in the browser (or on-device from a web/hybrid app), instead of
calling a cloud inference API for every request.

This is the "how do I actually build and ship this" companion to
[Browser AI](../04-browser-ai/), [WebGPU](../05-webgpu/), and
[Model Quantization](../08-model-quantization/) — those explain the underlying
tech, this one is architecture + libraries + deploy checklist from a frontend
dev's point of view.
