# Model Quantization — Further reading

- "A Survey of Quantization Methods for Efficient Neural Network Inference" (Gholami, Kim, Dong, Yao, Mahoney, Keutzer)
- GPTQ paper: "GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers" (Frantar et al.)
- AWQ paper: "AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration" (Lin et al.)
- QLoRA paper: "QLoRA: Efficient Finetuning of Quantized LLMs" (Dettmers et al.) — introduces NF4
- PyTorch quantization documentation (pytorch.org/docs, `torch.ao.quantization`)
- TensorFlow Lite model optimization guide (tensorflow.org/lite/performance/model_optimization)
- ONNX Runtime quantization documentation (onnxruntime.ai/docs/performance/quantization.html)
- llama.cpp repository README and its GGUF quantization type documentation (ggml-org/llama.cpp on GitHub)
