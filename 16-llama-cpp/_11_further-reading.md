# llama.cpp — Further reading

- `ggml-org/llama.cpp` GitHub repository — README, `docs/`, and `examples/` directories cover build options, server API, and grammar-constrained generation.
- The GGUF format specification within the repo (`gguf-py` package and `docs/gguf.md` equivalent).
- `abetlen/llama-cpp-python` GitHub repo for Python bindings and its OpenAI-compatible server mode.
- `withcatai/node-llama-cpp` documentation for Node.js integration.
- Model cards on Hugging Face tagged `gguf` (many uploaders, e.g. `bartowski` and `TheBloke` historically, publish ready-made GGUF quantizations of popular models).
