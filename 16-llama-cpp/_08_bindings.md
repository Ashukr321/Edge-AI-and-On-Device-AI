# llama.cpp — Bindings

- **llama-cpp-python** — Python bindings exposing both a low-level ctypes API and a high-level `Llama` class with an OpenAI-compatible server mode of its own; the most common way to embed llama.cpp in a Python application.
- **node-llama-cpp** — Node.js/TypeScript bindings with prebuilt binaries per platform, used for Electron apps and Node backends.
- Additional community bindings exist for Go, Rust, C#, and Java, of varying maintenance status — check activity before depending on one in production.
