# Edge AI Fundamentals — Tools & frameworks

- **TensorFlow Lite / LiteRT** — Google's mobile/embedded inference runtime.
- **ONNX Runtime** (with execution providers for CPU, CUDA, TensorRT,
  OpenVINO, CoreML, NNAPI/QNN) — cross-framework deployment.
- **NVIDIA TensorRT** — GPU-optimized inference for Jetson and datacenter GPUs.
- **Intel OpenVINO** — optimization/inference toolkit for Intel CPUs, iGPUs, VPUs.
- **Qualcomm AI Engine Direct / QNN SDK** — for Snapdragon Hexagon NPUs.
- **Edge Impulse** — end-to-end TinyML data collection, training, and deployment.
- **Apache TVM** — deep learning compiler stack targeting many backends.
