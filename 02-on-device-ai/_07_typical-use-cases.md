# On-Device AI — Typical use cases

- **Keyboard/text prediction** — next-word and autocorrect models (e.g.
  Gboard) running fully on-device per keystroke.
- **Camera features** — portrait mode/segmentation, scene detection,
  live text/OCR, real-time filters.
- **Voice assistants (offline mode)** — wake-word detection always runs
  on-device; some assistants now support fuller offline command handling.
- **Biometrics** — on-device face/fingerprint matching (never uploading
  biometric templates).
- **Health & fitness** — on-wearable heart-rate anomaly detection, fall
  detection, sleep staging.
- **On-device LLMs** — small (1B–8B parameter, quantized) language
  models for summarization, autocomplete, or assistant features without a
  server call, an area that has grown rapidly since 2023–2025.
